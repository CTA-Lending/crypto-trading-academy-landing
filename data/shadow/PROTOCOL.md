# 影子實驗預先登記書(PROTOCOL)
> 版本 v3.3(R17 封口版)｜登記日 2026-07-22｜**在看到任何結果前寫死,事後不得修改判定標準**
> 目的:防止實驗者(含 CEO 與 AI)在 90 天後「換指標說故事」或挑冠軍。

## 1. 實驗問題(primary hypothesis)
> LLM 自主決策的投資組合,在扣除可執行成本(費用、價差、真實資金費、換手)後,
> 相對「規則腦 + BTC 買進持有 + 等權多頭 + 純現金」這組基準,是否具有**正的主動報酬**,
> 且未以顯著更大的尾部風險換取報酬?

## 2. 受試者(9 個競爭者,不得中途增減)
| 類別 | 名稱 | 說明 |
|---|---|---|
| 規則基準 | rule | wick-break 雙向等權(確定性,無 AI) |
| 預測腦 | gpt / gemini / claude | 看候選表(含規則訊號)+ 自己持倉損益 |
| 純淨腦 | gpt_pure | **不看規則訊號**,只有價格與波動 |
| 存活腦 | guardian | Claude 底座 + 存活 prompt(**非獨立模型,與 claude 同家族計票**) |
| 市場基準 | bench_btc / bench_eqw / bench_cash | BTC 持有 / 等權多頭前10 / 純現金 |

## 3. 主要判定指標(primary metric,唯一)
**風險調整後主動報酬**:相對 `bench_eqw`(等權多頭)的 **Information Ratio**。
- 次要指標(僅供描述,不作勝負判定):總報酬、最大回撤、Sharpe、Calmar、換手率。
- **絕不以「總報酬最高」單獨判定勝負**(那會獎勵單純加大 beta 或運氣)。

## 4. 風險上限(任一觸發即該腦當期失格)
- 最大回撤 > 35%
- 發生強制平倉(爆倉)
- 正式違規(重試後仍違反曝險/幣種約束)率 > 10% 的決策日

## 5. 期間與 gate
- **Pilot:90 個決策日** = 工程與行為觀察期。**不足以判定真錢資格。**
- **真錢資格 gate:≥252 個決策日**,且必須涵蓋:一次 ≥20% 回撤、一次 ≥30% 單邊上漲、高波動與低波動各一段。
- Pilot 結束只能決定「是否繼續 shadow」,不得直接放真錢。

## 6. 統計方法(Pilot 結束時執行)——**參數在此鎖死,不得看完結果再選**
GPT 指出「只寫方法名稱、參數事後可選」仍留有研究者自由度,故逐項寫死:

| 項目 | 鎖定規則(唯一,無替代選項) |
|---|---|
| 報酬序列 | 每日**簡單報酬** `equity_t/equity_{t-1} − 1`;不用對數報酬 |
| 主動報酬 | `r_brain − r_bench_eqw`(逐日相減,不做 beta 調整) |
| IR 年化 | `mean(active)/std(active) × √252`;std 用**樣本標準差(ddof=1)** |
| HAC lag | **Newey–West,lag = floor(4×(T/100)^(2/9))**(Newey-West 1994 自動法則),T=有效決策日數;不做人工挑選 |
| Block bootstrap | **stationary bootstrap(Politis–Romano)**,期望 block 長度 `L = T^(1/3)` 取整,**重抽 10,000 次**,雙尾 **95%** 百分位信賴區間;亂數種子 **20260722** |
| Deflated Sharpe | Bailey–López de Prado (2014) 原式;試驗數 **N = 9**(全體競爭者),偏度與峰度用**樣本估計值**(Fisher 定義,ddof=1) |
| 因子迴歸 | **日頻**;`r_brain = α + β·r_BTC + ε`,含截距;**單因子,不事後追加因子**;α 以上述 HAC 標準誤檢定 |
| 顯著水準 | 雙尾 **α = 0.05**;多重比較僅以 DSR 校正,不另做 Bonferroni |
| 缺失日 | 該日**整體不執行** → 全體同時剔除(不補值、不前推);記於 CHANGELOG |
| stale 日 | 照常計入;另出「排除 stale 日」的敏感度分析,**但主結論以含 stale 為準** |
| fallback funding 日 | 統計凍結前**必須回補真實費率**;無法回補者標記並同時報告含/不含兩版 |
| infra_skip 日 | 照常計入(維持原倉也是一種結果),不得剔除 |
| 基準成本 | benchmark 與受試者**適用完全相同**的費用/價差/資金費/清算規則 |

**盲化**:統計程式在開發與除錯期間只用代號(A–I),對應表於凍結後才揭露。

### 6.0 實作邊界規則(GPT R17:方法名稱不等於沒有自由度)
統計程式 `shadow/stats.py` 已於 **Day 0(零真實結果)** 完成、測試(20 項)並隨程式碼錨定。
以下邊界唯一指定,無替代選項:
- **stationary bootstrap 採 circular wrapping**(索引到尾端繞回開頭);`p = 1/L`,`L = round(T^(1/3))`
- 亂數來源 = Python 標準庫 `random.Random(20260722)`,逐位元可重現
- **零變異**(std < 1e-12):IR/Sharpe/DSR 一律回報 `None`,**不得**回報無限大
- **樣本 < 30 個決策日**:只出描述統計,**不報 p 值**(防早期宣稱勝負)
- **HAC 用於兩處**:①平均主動報酬的 t 檢定 ②因子迴歸截距 α 的 t 檢定;Bartlett 核權重 `1 − l/(L+1)`,除以 T
- **DSR 的 γ4 = 原始峰度**(常態 = 3,非 excess);跨試驗 Sharpe 變異數用 9 個競爭者的**日 Sharpe** 樣本變異數(ddof=1)
- **長度不一致直接報錯**,不做任何對齊猜測(缺失日必須全體同時剔除)

### 6.1 診斷組(不列入 9 名 primary competitors)
- **共同 optimizer 消融**:`gpt_pure` 已是「不看規則訊號」的消融組,用於歸因
  「效果來自 LLM 判斷,還是來自共同的 wick-break 訊號」。
  此比較為**診斷性**,不參與主排名、不進 DSR 的 N。

## 7. 成本與執行假設(已寫入程式,不得事後放寬)
- 費用 5bps + 半價差(主流 2bps / 其他 12bps)
- 真實資金費(逐 settlement 累加)
- 執行價 = **決策完成後**抓取之即時市價(含 LLM 推理延遲)
- 維持保證金率 **固定 5%**(標準化合成保證金制度,**非** Binance 各幣分級 schedule;
  對外不得稱為「Binance 真實爆倉率」),跌破強制平倉並收 50bps 清算費
- **強平成交價唯一規則**:= 該幣不利極值 + side-aware 半價差(與一般換倉同一價差模型)
- **當日事件順序唯一化**:①P0 估值 → ②資金費 → ③日內爆倉檢查 → ④結算點爆倉檢查
  → ⑤決策 → ⑥P1 換倉。**強平當日該腦不得再建倉**(目標強制為空手)
- 日內爆倉採「各標的同時取最不利極值」= 刻意的**壓力情境**,非可還原的市場路徑,
  報告須如此稱呼
- 總曝險 ≤100%(無槓桿);違規重試一次仍違規 → 維持原倉
- 假設本金 $10,000,**未計入大額訂單的市場衝擊成本**

## 11. 計價單位與 USDT 脫鉤規則(Day 1 前預先登記)

  **不得**在看到結果後才改用對自己有利的計價。

## 12. 執行價與可成交性(Day 1 前預先登記)
- 無 L1 bid/ask 來源,故採**方向性固定半價差**:買進 `mid×(1+s)`、賣出 `mid×(1−s)`,
  `s` = 主流 2bps / 其他 12bps,**跑完不得調參**。
- **市場衝擊未計入**(本金 $10,000);結論不得外推至大資金。
- **不可成交資產不得假裝成交**:連續無報價達上限而強制出場者,一律套用
  預先登記的 **20% haircut**,並在報告中單獨列出受影響筆數。
- **haircut 必須雙向不利**(GPT R17):多單被迫賣出 `p×0.8`、空單被迫買回 `p×1.2`。
  一律 `×0.8` 會讓空單因無報價而受益,等於送禮。
