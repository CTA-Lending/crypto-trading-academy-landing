📋 領取前準備

1. Bitfinex 已完成 KYC： 基礎驗證即可，加密幣放貸不需要進階驗證。
2. 入金幣種選 USD（不是 USDT）： USD 利率最高、流動性最好。USDT 也可，但收益較低。

4. 建議至少 $150 USD： Bitfinex 放貸最低 $150。低於此金額 Bot 無法掛單，試用會浪費。
5. API Key 只開最小權限： 建立 API 時 務必照教學文逐項切換 14 個開關（8 開 6 關），提款、訂單、保證金交易全關，IP 白名單欄位請留空。

🚀 5 步驟領取試用

Step 1 — 註冊會員中心

前往 app.crypto-trading-academy.com/register 用 Email 或 Google 登入註冊。建議用常用 Email，方便日後通知。

Step 2 — 綁定 Telegram（必須）

登入後到「設定 → Telegram 綁定」，掃 QR code 或點連結加入 Bot： @CTA_LendingBot。

⚠️ 沒有綁定 TG 不能領試用 — 因為到期通知必須能送達您，避免錯過續費。

Step 3 — 商城領取試用

前往 會員中心商城， 頁面頂部會顯示「免費領取 14 天 Pro 試用」卡片。

點「立即領取」會跳出雙重確認 — 勾選兩項確認框後送出，試用立即啟動。

Step 4 — 到 TG Bot 設定 Bitfinex API

回到 Telegram @CTA_LendingBot， 按「設定 API」，依序貼上 API Key 和 API Secret。

系統驗證通過後，Bot 立刻開始自動掛單放貸。

Step 5 — 確認 Bitfinex 自動續約已關閉

Bitfinex 預設會把已借出的單「自動續約」，這會跟智能放貸衝突。

到 Bitfinex → Funding → 已借出，把每筆單的 Auto-Renew 關掉。 Bot 偵測到衝突會主動 TG 提醒您。

⏰ 試用期間會收到哪些通知？

  • 到期前 3 天：TG 提醒您快到期
  • 到期前 1 天：TG 警示「明天 Bot 會暫停」
  • 到期當天：Bot 暫停，TG 通知
  • 到期隔天：再推一次升級提醒

會員中心也會全程顯示倒數 Banner（後台第三層保護），就算漏看 TG 也能在登入時看到。

❓ 常見問題

試用結束會自動扣款嗎？

不會。試用結束 Bot 會直接暫停，您必須主動到商城選方案訂閱才會恢復服務。沒有偷扣款。

我以前是付費會員，能再領 14 天試用嗎？

不行。試用是給「從未付費」的新用戶體驗用的，每位用戶一輩子只能領一次。 如果您之前是付費會員續費中斷，請直接到商城選方案恢復。

試用期間我想提早升級付費，會浪費剩下的天數嗎？

不會浪費 — 但試用會被新付費訂閱取代，剩下天數會折抵到付費訂閱的開始日（即您升級當下立刻啟用付費期，後續從付費期開始算）。

沒有 Telegram 帳號可以試用嗎？

目前必須綁 TG 才能領試用，因為到期通知/警報都走 TG。註冊 Telegram 是免費的，5 分鐘可完成。

試用 14 天我能放多少？預期收益？

沒有上限（Bitfinex 規則內）。年化利率波動大（過去區間約 5%~30% APR），實際收益依市況。 14 天是讓您體驗 Bot 自動掛單、利率追蹤、警報、報表等完整功能。

⚠️ 風險揭露

放貸有對手違約、平台故障、市況導致利率為零等風險。本服務為「自動掛單工具」，不保證收益、不代操、不接觸您的本金。資金始終在您 Bitfinex 帳戶，本平台只透過 API 為您下單。請依個人風險承擔能力決定資金規模。
