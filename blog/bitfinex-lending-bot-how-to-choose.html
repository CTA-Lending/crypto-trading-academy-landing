放貸機器人怎麼選？挑 Bitfinex 放貸工具前，先看這 6 件事

2026 年 10 月 26 日 | 閱讀時間約 6 分鐘

Bitfinex 的放貸機器人這幾年選擇變多，網路上的比較文也不少，但很多比較只看價格和宣傳的年化數字。這篇不比哪一家最好，而是整理我們認為挑工具前最該先看的 6 件事——你可以拿這份清單去檢查任何一家，包括我們自己。

先講結論：挑放貸機器人，先看這 6 件事

  1. 要你開哪些 API 權限——提款權限一定要關
  2. 資金是不是一直在你自己的帳戶
  3. 怎麼收費，換算成你的資金規模划不划算
  4. 掛單邏輯說不說得清楚
  5. 能不能先試用、想停的時候怎麼停
  6. 績效數字有沒有交代期間、口徑和費用

1. API 權限：只給必要的，提款一定關

放貸機器人是透過 Bitfinex 的 API Key 幫你掛單。API Key 就像一把可以設定權限的鑰匙，你給多少權限，工具就能做多少事：

  • 提款（Withdraw）權限 — 一定要關。放貸工具不需要把錢提領出去。
  • 下單交易權限 — 放貸工具通常也不需要。如果工具要你開交易權限，先問清楚原因。
  • 融資相關權限 — 掛放貸單、取消放貸單需要。
  • 讀取、錢包間轉移 — 有些工具會用來讀取餘額、把資金轉進融資錢包；開之前問清楚用途。

要知道的是，就算關掉提款權限，API Key 外洩時仍可能被拿來亂掛融資單或搬移錢包資金，所以金鑰要妥善保管，懷疑外洩就立刻到 Bitfinex 刪除。實際設定步驟可以參考Bitfinex 註冊開戶 + API 設定完整教學。

另外可以問工具支不支援固定的 IP 白名單。能限制來源 IP 比較安全；如果工具的伺服器 IP 會變動、只能設成不限制，就代表這把金鑰不受來源限制，要更注意保管。

2. 資金在誰手上

採非託管模式、而且沒有拿到提款權限的放貸機器人，資金會一直留在你名下的 Bitfinex 帳戶（由 Bitfinex 保管），工具只是依你給的權限幫你掛單。這跟「把錢轉給別人幫你操作」是兩回事，風險結構完全不同。看到下面這些情況，要特別小心：

  • 要你把資金轉到工具方的帳戶或錢包
  • 標榜「保本」「保證收益」「穩定配息」
  • 工具方另外限制你提領本金，或在正常放貸期之外要求綁約、鎖定資金

資金在自己帳戶，不代表沒有風險：Bitfinex 本身的平台風險、極端行情下強制平倉來不及的風險、利率波動都還在。這部分可以看為什麼 Bitfinex 放貸利率這麼高？裡的風險說明。

3. 收費方式：換算成你的資金規模

常見的收費方式有兩種：

  • 訂閱制 — 每月或每年固定費用。好處是費用固定、不隨收益變動；但資金小的時候，費用佔利息的比例會很高。
  • 抽成制 — 從你的利息裡抽一定比例。好處是資金小時負擔低；但資金越大、利息越多，費用也跟著變多。

沒有哪一種一定比較好，重點是換算：用「一年的工具費用 ÷ 你預估一年的利息」，看看佔多少。另外別忘了，Bitfinex 本身會從一般融資掛單的利息中收取 15% 手續費（以官方當期費率表為準），這筆跟工具費用是分開算的。

4. 掛單邏輯：說得清楚，才好判斷

放貸機器人的核心是「掛什麼利率、掛多少天、拆成幾筆」。一個工具應該能用白話說明它怎麼決定，而不是只寫「AI 智能」。你可以問這幾個問題：

  • 利率怎麼定？ — 是跟著市場平均，還是參考訂單簿上的報價分布？
  • 天期怎麼選？ — 利率低的時候，會不會把錢鎖太久？
  • 多久重新掛一次？ — 依 Bitfinex 的撮合規則，同樣利率的掛單是照掛出的先後排隊；取消後再掛，就要重新排隊，所以頻繁重掛不一定比較好。
  • 怎樣才會成交？ — Bitfinex 的融資撮合要利率和天期都對得上，所以天期很長、利率很高的單，可能要等比較久才有人借。

這些問題沒有標準答案，但如果工具連自己的做法都說不清楚，你就很難判斷它適不適合你。

5. 試用與退出：先試、能停

  • 有沒有免費試用？試用結束會不會自動扣款？
  • 想停的時候在哪裡停？停了之後，工具會不會把還沒成交的掛單撤掉？
  • 已經借出去的資金，放貸方通常不能要求提前收回，要等到期或借款人提前還款。
  • 要停止新的自動放貸：先到 Bitfinex 後台刪除那組 API Key，再關閉平台的到期自動續借（如果有開），最後檢查、取消還沒成交的掛單。只刪金鑰的話，已經掛在市場上的單不會自動取消，之後仍可能成交；已經借出去的資金，仍要等到期或借款人提前還款。

另外提醒，Bitfinex 本身有到期自動續借的設定；跟工具同時開，可能會互相干擾，用工具前記得確認。

6. 績效數字：先看計算口徑

放貸工具最常拿來宣傳的是年化數字。看到數字時，先問這幾件事：

  • 期間多長？是某一週、某一個月，還是好幾年？
  • 是哪一種數字？掛單利率、成交利率，還是帳戶實際到手的報酬？
  • 有沒有扣掉 Bitfinex 的手續費、資金閒置時間和工具費用？
  • 是少數用戶的截圖，還是全體用戶的統計？
  • 有沒有寫「保證」「穩定」這類字？放貸利率是浮動的，這類說法本身就是警訊。

如果你在我們其他文章裡看到「USD 放貸年化約 8%～15%」，也要照這個標準看：它是 CEO 依過往經驗、並參考同類工具公開成績提出的參考區間，不是回測、不是 Bitfinex 全市場統計，也不代表 CTA 工具的績效；它沒有區分扣除手續費前後，也沒有可比較的觀察期間與樣本，不能拿來推估你的報酬（過去表現不代表未來收益；浮動利率，不構成收益承諾）。看懂利率數字的方法，可以參考APR vs APY 完整解析和為什麼每天領到的利息不一樣。

常見問題

放貸機器人一定比手動好嗎？

不一定。資金小、願意自己花時間的人，手動或 Bitfinex 內建的功能可能就夠用。工具的價值在於省下重複掛單的時間、減少沒及時重掛的閒置；但它也有費用，要自己算划不划算。

小資金適合用放貸機器人嗎？

先算費用佔比。Bitfinex 對單筆融資掛單有最低金額限制（約 150 美元等值，以官方當期規則為準）；資金太小時，工具費用可能吃掉大部分利息。

API Key 外洩會怎樣？

沒開提款權限的話，對方不能用它把資金提領到外部；但仍可能被拿來亂掛或取消融資單、在你的錢包之間搬移資金。發現異常請立刻到 Bitfinex 刪除那組 API Key、檢查有沒有不明的掛單，並檢查帳號密碼與 2FA。

用了放貸機器人，還需要自己看嗎？

需要。至少要定期看成交狀況、費用、平台公告，以及 API Key 有沒有異常。工具省的是重複動作，不是你的判斷。
