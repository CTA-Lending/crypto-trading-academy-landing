放貸專區 ｜ API 安全

Bitfinex API 權限怎麼開才安全？
放貸工具要哪幾個

Bitfinex 的 API 金鑰可以一項一項設定權限。放貸工具的核心是「保證金融資」這一類；以我們自己的放貸程式為例，只用到 4 個開關：保證金融資的讀取與寫入、錢包的讀取、帳戶歷史的讀取。提款、訂單、保證金交易、錢包間轉移都不用開。這篇把官方分的九項權限逐項講清楚，附上 IP 限制怎麼設、關掉提款後還剩哪些風險；官方說法都附 Bitfinex 原文出處。

📅 2026-11-11•⏱ 閱讀約 8 分鐘•✍️ 交易幣修課研究室

先講答案

  1. 以我們自己的放貸程式為例，只用到 4 個開關：保證金融資的讀取與寫入、錢包的讀取、帳戶歷史的讀取。放貸在 Bitfinex 叫「保證金融資」（Margin Funding），這一類是放貸工具的核心。
  2. 提款、訂單、保證金交易、錢包間轉移，我們的程式都沒有用到，不用開。
  3. Bitfinex 的 API 金鑰（API Key）可以一項一項設定權限。官方說明文章把權限分成九項：帳戶資訊、帳戶歷史紀錄、訂單、保證金交易、保證金融資、錢包、提款、Bitfinex Pay 這八類功能，加上 IP 位址訪問限制。不少類別底下有讀、寫兩個開關，所以畫面上的開關數比九多。
  4. IP 限制：每把金鑰最多可以填 20 個 IP，填了以後金鑰只能從這些 IP 使用。Bitfinex 官方部落格建議，用自動化工具時把金鑰限制在白名單 IP。
  5. 關掉提款不等於沒有風險。拿到金鑰的人仍然可以亂掛或取消你的放貸單。金鑰要當成密碼保管，懷疑外洩就立刻到 Bitfinex 撤銷。

先揭露：交易幣修課（CTA）自己提供 Bitfinex 放貸自動化工具，是付費訂閱服務，我們因此有收入。這篇裡「放貸工具要開哪幾個」講的是我們自己的程式；別家工具用到的權限可能不同，請以該工具的說明為準。Bitfinex 官方的說法，在正文各段附上出處，文末有完整清單，查閱日是 2026 年 11 月 11 日。

一、API 金鑰是什麼

API 金鑰是你在 Bitfinex 帳戶裡自己建立的一組憑證，由兩串字組成：API Key 和 API Key Secret。把這兩串字交給一個程式，那個程式就能用你的帳戶做事。能做哪些事，由你建立金鑰時打開的權限決定。

可以把它想成一把能設定「開得了哪幾扇門」的鑰匙。能開的門越少，鑰匙外洩後，別人能做的事就越少。

Bitfinex 的 API 文件把權限分成「讀」和「寫」：只想讓程式看帳戶資料，勾「讀」就夠；要讓程式交易或申請出入金，才需要另外勾對應的「寫」（出處：Requirements and Limitations↗）。

「只給用得到的權限」這件事，官方自己示範過：Bitfinex 的報表程式只需要讀取權限，官方在說明裡寫明，為了帳戶安全，不建議給它寫入權限（出處：Full Tax Report — Bitfinex Reporting Application↗）。

建立金鑰的流程，官方說明是這樣的（出處：How to create and revoke a Bitfinex API Key↗）：

  1. 選好權限，幫金鑰取一個備註名稱，按下產生。
  2. 輸入兩步驟驗證（2FA）的驗證碼。
  3. 到信箱點確認信裡的按鈕。官方提醒，要用開著 Bitfinex 的同一個瀏覽器打開確認連結；如果點下去開到別的瀏覽器（手機上常會開在郵件 App 裡），把連結複製回原本的瀏覽器打開。
  4. 頁面顯示 API Key 和 API Key Secret。官方寫明金鑰資訊只會顯示這一次，並提醒不要把金鑰存放在網路上，以免被盜用。

每一步的畫面截圖，在 Bitfinex 註冊開戶 + API 設定完整教學。這篇只講權限怎麼選。

設定時請注意兩件事：

  • 按名稱逐項對照，不要只數個數。 實際畫面上有幾個開關，可能隨介面版本不同。官方說明文章列了 Bitfinex Pay、沒有列 Settings；官方 API 文件的權限代號裡兩個都有；我們 2026 年 5 月截到的中文介面有 Settings、沒有 Bitfinex Pay，一共 15 個開關。
  • Settings 這一類（Read account settings、Write account settings）：我們的程式沒有用到，兩個都不用開。

三、放貸工具要開哪幾個：以我們的程式為例，4 個

放貸程式做的事很單純：看你的 Funding 錢包（放貸用的錢包；Bitfinex 帳戶預設有三個錢包↗，要借出去的錢得先放在這一個）有多少錢，依你的設定掛出放貸單，該取消的取消，把每天收到的利息記下來。對應到 Bitfinex 中文介面，我們的程式只用到這 4 個開關：

開關（中文介面上的字樣） 屬於哪一類 程式拿它做什麼
提供、取消及關閉融資 保證金融資（寫入） 掛出放貸單、取消放貸單
查閱融資狀態及信息 保證金融資（讀取） 看哪些單還在掛、哪些已經借出
查閱錢包餘額及地址 錢包（讀取） 看 Funding 錢包有多少錢可以掛
查閱歷史餘額及交易紀錄 帳戶歷史（讀取）；介面上寫「賬戶歷史」 讀每天的利息入帳紀錄，用來算收益

用英文介面的話：保證金融資請找 Margin Funding 這一類底下的兩個開關；錢包的讀取是 Wallets 底下的 Get wallet balances and addresses；帳戶歷史是 Account History 這一類（只有一個開關）。

這 4 個是怎麼來的、適用到哪裡，有兩點要說清楚：

  • 這是查我們自己的程式碼確認的，不是 Bitfinex 公布的對照。 2026 年 11 月 11 日，我們查閱自家放貸程式在線上執行的程式碼，確認它只用到上表這 4 類功能。Bitfinex 的 API 文件沒有逐一寫明「哪個功能要開哪個開關」，所以功能對應到哪個開關，是我們依官方對各分類的描述推得的。綁定後如果出現權限相關的錯誤，請回到 Bitfinex 的 API Keys 頁，對照這 4 個開關有沒有打開。
  • 別家工具可能不一樣。 有的工具會多要「錢包間轉移」（幫你把錢搬進 Funding 錢包）或其他項目。多出來的每一項，都值得先問清楚用途再開。怎麼比較不同的放貸工具，可以看 Bitfinex 放貸機器人怎麼選。

四、哪些不要開，為什麼

提款：絕對不要開

官方對這一類的描述只有一句：透過 API 啟用提款。它在畫面上是獨立的一區、獨立的開關，中文介面寫「建立提款請求」，英文介面寫 Create a new withdrawal。

放貸不需要把錢領到外部。如果有放貸工具要你開這一項，先停下來問清楚。

訂單、保證金交易：放貸用不到

這兩類管的是下單買賣和槓桿倉位。放貸不是交易，掛放貸單走的是「保證金融資」那一類。

錢包間轉移：跟提款是兩回事，但用不到就別開

「於錢包間轉移資金」跟提款是兩個獨立的開關，分屬錢包、提款兩類。官方的錢包說明也寫，要把資金送到外部錢包得走提款（出處：How to transfer funds between Bitfinex wallets↗）。

不過轉移能做的事，比名字聽起來多。官方 API 文件寫到，轉移這個功能除了在幾個錢包之間搬錢，還可以把 USDT 轉成衍生品用的 USDT0，另有參數可以把資金轉到以 email 或使用者編號指定的主帳戶或子帳戶（出處：Transfer Between Wallets↗）。只開「於錢包間轉移資金」這一個開關，是不是就做得到這些，官方文件沒有寫明。

我們的程式沒有用到這個開關。資金請自己在 Bitfinex 的錢包頁轉到 Funding 錢包，官方說明寫錢包之間搬移免費、幾秒就完成。

其餘幾項

編輯帳戶訊息、查閱帳戶手續費、Settings 的兩個開關、Bitfinex Pay：我們的程式都沒有用到，全部關著就好。

五、IP 限制：讓金鑰只能從指定的地方使用

權限管的是「這把鑰匙開得了哪些門」，IP 限制管的是「從哪裡來的人拿這把鑰匙才有用」。

官方說明：每把 API 金鑰最多可以列 20 個 IP 位址，設了之後金鑰只能從這些 IP 使用。Bitfinex 官方部落格的安全清單也建議，使用自動化交易或整合工具時，把 API 金鑰限制在白名單 IP（出處：Lock Down Your Crypto: The Ultimate Security Checklist for Bitfinex Traders↗）。

以我們的工具為例：

  • 建議在金鑰的 IP 限制填我們放貸伺服器的 IP，只有一組。這組 IP 請登入會員後台，到 API Key 設定頁查看（Telegram 放貸機器人的金鑰教學裡也有），照頁面上顯示的原樣貼上，前後不要多出空格。
  • 填了之後，把「允許從任何IP位址訪問」這個開關關掉。這個開關在我們 2026 年 5 月看到的畫面上，就在權限清單最下面；如果你的畫面沒有這個開關，只要填好 IP 就可以。
  • 不填也能用，但這把金鑰就不受來源 IP 限制，比較不安全；不填的話，「允許從任何IP位址訪問」要保持打開。
  • 不要填你自己家裡或手機的 IP。工具是從我們的伺服器連到 Bitfinex 的，填你家的 IP 會把工具擋在外面。
  • 這個 IP 限制只套用在這一把金鑰上，不會影響你自己用網站或手機 App 登入 Bitfinex。

別跟「帳號登入的 IP 白名單」搞混。 Bitfinex 另外有一個帳號層級的 IP 設定，在帳戶的安全設定頁，限制的是哪些 IP 可以存取你的帳戶。官方說明提醒，多數人的網路不是固定 IP，設錯會把自己鎖在帳戶外面；IP 會變動、或需要在多個裝置和地點登入的人，官方不建議開這個功能（出處：Getting Set Up: Securing Your Bitfinex Account↗）。這篇講的是建立 API 金鑰時的 IP 限制，是另一個功能。

六、關掉提款，不等於沒有風險

只開上面 4 個開關、關掉提款，拿到金鑰的人沒辦法用這把金鑰送出提款請求。如果你照第五節設了 IP 限制，官方說明是金鑰只能從列出的 IP 使用，這也能擋掉一部分風險；沒設的話，這道阻擋就不存在。能用這把金鑰的人，還有兩件事做得到：

  • 看得到你的資料：錢包餘額、歷史紀錄、放貸狀態。
  • 動得了你的放貸單：可以掛出放貸單，也可以取消放貸單。例如用很低的利率、很長的天期把你的資金借出去，或把你原本掛好的單取消。

Bitfinex 官方部落格有一篇談 AI 交易代理人的風險，講的是同一個道理：限制權限、關掉提款是重要的第一步，但只解決一部分問題，有執行權的程式仍然可能用錯誤的操作造成損失。那篇談的是交易機器人；套用到放貸是我們的類推，不是官方原話（出處：AI Trading Agents: Useful Tool or Security Liability?↗）。

所以金鑰本身要保管好。官方的提醒散在幾個地方：

  • 懷疑外洩就立刻撤銷。 官方 API 文件寫，依權限設定不同，外洩的金鑰可能讓人取得帳戶的完整存取並造成資金損失（出處：Requirements and Limitations↗）。
  • 不要把金鑰存放在網路上。 這是建立金鑰說明裡的提醒（出處：How to create and revoke a Bitfinex API Key↗）。要留備份的話，存在不連網的地方，例如寫在紙上鎖好；不要貼在聊天訊息、信箱草稿或共用的雲端文件裡。其實金鑰交給工具之後，你自己不一定要留：哪天需要，撤銷舊的、重建一把就好。
  • 小心要你交出金鑰的網站。 官方的防詐說明把「要求你交出帳戶 API 金鑰的詐騙網站」列為釣魚手法之一（出處：How to protect a Bitfinex account from phishing scams↗）。輸入金鑰之前，先確認網址是你要用的那個工具的官方網址。
  • 定期換一把新的。 上面那篇官方部落格建議金鑰要定期輪換，舊的憑證要從交易所和工具兩邊都刪掉。多久換一次，官方沒有給數字。

七、建好之後：檢查、修改、撤銷

下面修改與撤銷的步驟，出自官方的建立金鑰說明（出處：How to create and revoke a Bitfinex API Key↗）。

修改權限。 到 API 頁的 My API Keys 分頁，點 Permissions > Edit，調整後按頁面底部的 Update Permissions，再輸入 2FA 驗證碼。也就是說，建好之後才發現多開了幾項，不用重建，把多的關掉就可以。

撤銷金鑰。 同一個分頁的 Action 欄選 Revoke。官方說明寫，撤銷會自動移除這把金鑰使用的所有權限。

撤銷之後，請自己再檢查兩件事。官方說明沒有寫撤銷金鑰會不會連帶處理它們：

  1. 還沒成交的放貸掛單：到 Funding 頁看一下，不想留的自己取消。
  2. Bitfinex 本身的到期自動續借設定：如果你也想停止自動續借，記得一併關掉。

已經借出去的資金，請到 Funding 頁查看各筆的狀態與到期日。

忘了存 Secret。 金鑰資訊只完整顯示一次，之後找不回來。官方 API 文件寫，只要還能登入帳戶和信箱，隨時可以再產生新的金鑰；所以做法是撤銷舊的、重建一把（出處：Requirements and Limitations↗）。

設定完的檢查清單

  • 打開的只有工具用得到的開關（我們的工具是 4 個）
  • 提款是關的
  • 訂單、保證金交易是關的
  • 錢包間轉移是關的（除非你用的工具需要，而且你清楚它的用途）
  • IP 限制填了工具伺服器的 IP；畫面上有「允許從任何IP位址訪問」的話，它是關的。或者你清楚不填的代價
  • 自己另外留的 Key 和 Secret 備份沒有存在網路上，也沒有貼在聊天訊息或共用文件裡
  • 金鑰的備註名稱看得出是給哪個工具用的（之後要撤銷時才不會刪錯）
  • 帳戶的兩步驟驗證（2FA）開著

常見問題

Bitfinex 放貸要開哪幾個 API 權限？

以我們的放貸程式為例，只要開 4 個：保證金融資的「提供、取消及關閉融資」與「查閱融資狀態及信息」、錢包的「查閱錢包餘額及地址」、帳戶歷史的「查閱歷史餘額及交易紀錄」；其餘都不用開。別家工具可能不同，請以該工具的說明為準。

把 API Key 交給放貸工具安全嗎？

要看你開了哪些權限、有沒有設 IP 限制，以及金鑰有沒有保管好。照這篇的設定，我們的工具拿到的是 4 個開關（保證金融資的讀取與寫入、錢包的讀取、帳戶歷史的讀取），沒有提款、錢包間轉移和下單交易的權限，所以不能用這把金鑰把資金提領到外部；我們也不託管你的資金。但金鑰外洩時，你的帳戶資料仍可能被看到、放貸單仍可能被亂掛或取消，所以金鑰要妥善保管；懷疑外洩或想取消授權時，到 Bitfinex 撤銷這把金鑰。

放貸機器人需要開提款權限嗎？

不需要。放貸是把 Funding 錢包裡的錢掛出去借給別人，用到的是「保證金融資」這一類，不需要把錢領到外部。如果有放貸工具要你開提款，先停下來問清楚。

「於錢包間轉移資金」要不要開？

我們的程式沒有用到，不用開；資金請自己在 Bitfinex 的錢包頁轉到 Funding 錢包。它跟提款是兩個獨立的開關。不過依官方 API 文件，轉移功能還可以把 USDT 轉成 USDT0，也有參數可以把資金轉到主帳戶或子帳戶；只開這個開關是不是就做得到這些，官方沒有寫明。用不到就不要開。

IP 限制要填什麼？不填可以嗎？

用我們的工具，建議填我們放貸伺服器的 IP（只有一組，登入會員後台的 API Key 設定頁可以看到），畫面上有「允許從任何IP位址訪問」的話把它關掉。不填也能用，但金鑰就不受來源 IP 限制，比較不安全。不要填你自己家裡或手機的 IP。

金鑰建好之後，還能改權限嗎？

可以。到 My API Keys 分頁點 Permissions > Edit，調整後按 Update Permissions，再輸入 2FA 驗證碼，不用重建金鑰。

懷疑金鑰外洩怎麼辦？

立刻到 Bitfinex 的 My API Keys 分頁撤銷（Revoke）那把金鑰。接著到 Funding 頁檢查有沒有不是你掛的放貸單，把不想留的取消；再確認 Bitfinex 的自動續借設定；已經借出去的資金，到 Funding 頁查看各筆的狀態與到期日。之後需要的話，重建一把新的金鑰。

忘記存 API Secret 怎麼辦？

金鑰資訊只完整顯示一次，找不回來。撤銷舊的金鑰，重新建立一把；新的金鑰產生後，當場貼到工具裡設定好。要另外留備份的話，照第六節的方式離線保管。
