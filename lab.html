🔐 自己驗:不需要相信我們

這一頁以前寫著「帳本不可竄改」,而在 2026-09-05 之前, 那條鏈從來沒有被任何程式驗證過,也沒有任何入口讓你自己驗。 ⭐ 一條沒有人驗證的雜湊鏈是裝飾品,不是證據。

現在驗證程式跟鏈一起公開。它只用 Python 標準庫, 不需要我們的任何其他程式碼:

# 一次抓齊:驗證器 + 鏈 + 鏈所保護的四個檔案
B=https://crypto-trading-academy.com/data/shadow
for f in verify_chain.py anchor_chain.json dashboard_data.json CHANGELOG.md PROTOCOL.md diaries.json; do curl -sO $B/$f; done

python verify_chain.py

⚠️ 少下載任何一個檔,那一項會顯示「本機沒有這個檔案」—— 那是沒有比對到,不是「通過」。這支程式把三種結果分開:通過 / 不符 / 沒有檔案可比對。

🔴 它會自己印出它證明不了什麼,請一起讀: 雜湊鏈只防「改掉其中一筆」,防不了「整條重算」。 防重算靠的是每日推到公開 git repo 留下的外部時間戳 —— 那份證據在 git 歷史裡,不在那支程式裡。

⚠️ 還有一件我們現在做不到的事: 驗證程式證明的是「GitHub 上那份檔案沒被改」, 而你正在看的是這個網頁 —— 網頁本身不會在你的瀏覽器裡即時比對雜湊。 所以「你螢幕上的數字 = 被錨定的那一份」這件事,我們目前沒有給你證明。 要自己確認,請用上面的指令下載原始檔比對。

📌 錨點是每天 00:36 UTC 拍一次快照。 我們當天稍後更新過檔案時,驗證器會顯示「不符」並說明它分辨不出 「正常更新」與「被竄改」—— 那時請看 git 歷史。
